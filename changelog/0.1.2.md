# tinysampler 0.1.2

Дата снимка: 2026-09-19. Соответствует пакету `tinysampler` **0.1.2**.

Опирается на [0.1.1](0.1.1.md). Здесь — дельта после нарезки пэдов в регионы и студийных «колбасок» с пианороллом.

## Что изменилось относительно 0.1.1

### Инструмент сэмплинга

- Чоп пэда — **отрезок**, не точка: `start_index` (включительно) и `end_index` (исключительно).
- На waveform две полоски границ. Двигать можно **только за треугольники-ярлычки** снаружи региона (сторона 24 px):
  - левый — прямоугольный треугольник на верхней границе (катет сверху);
  - правый — на нижней границе (катет снизу).
- Свободный пэд по-прежнему вешается на базовый курсор; длина по умолчанию — доля такта от темпа трека (не короче минимума).
- Занятый пэд играет **только свой отрезок** (превью с `end_secs`), а не до конца файла.
- Загрузка нового сэмпла сбрасывает чопы и ноты этого трека в пианоролле.

### Студия: колбаски вместо waveform на дорожке

- Исходный клип-сэмпл на таймлайне **не рисуется и не звучит**. Микс — только ноты внутри sequence-клипов («колбасок»).
- Новый трек сразу получает колбаску на 4 такта с нуля (4/4 от `tempo_bpm`).
- Колбаска: мини-обзор нот внутри; тело — двигать; левый/правый край — укоротить/удлинить (слева контент остаётся на месте); `Delete` — удалить выделенную колбаску (и её ноты).
- Двойной клик по колбаске открывает пианоролл. Двойной клик по пустой дорожке — новая колбаска.
- Ctrl+K (split исходного клипа) в студии больше не режет сэмпл.

### Пианоролл (модальное окно)

Как инструмент сэмплинга: затемнение Middle (`interactable(false)`), окно Foreground; студия некликабельна.

- 16 клавиш (Q–I / A–K) и ритм-сетка шестнадцатыми от темпа проекта.
- ЛКМ по сетке ставит ноту нарезанного пэда (длительность чопа, вверх до сетки). Ненарезанный пэд не ставится.
- Ноту можно двигать по времени и ряду, тянуть правый край; **ПКМ** удаляет.
- Q–I / A–K: звук **пока клавиша зажата**; отпустил — сразу стоп. После конца чопа тишина, автоповтор Windows не перезапускает сэмпл.
- Превью пэда из пианоролла **не глушит** транспорт: при play слышно и ноты колбаски, и зажатый пэд.
- Escape / × закрывает окно. Размер окна не растёт от статуса: подсказка и сообщение делят одну строку.

### Сохранение

- `pad_markers`: пишутся `start_index` / `end_index`. Старый `sample_index` при загрузке становится началом; конец — длина по умолчанию.
- `seq_clips[]`, `notes[]`, `next_seq_id`, `next_note_id`.
- Ноты с одним `track_index` без `seq_id` (если такие попадутся) собираются в колбаску на этот трек.
- `format` по-прежнему **1**. Не пишутся: зум пианоролла, какая колбаска открыта, зажатый пэд.

## Горячие клавиши

Студия — как в 0.1 / 0.1.1, с уточнениями:

| Клавиша | Действие |
|---|---|
| Delete | Выделенная метка 1–9, иначе выделенная колбаска |
| Ctrl+K | не режет клип |

Пианоролл (окно открыто):

| Клавиша | Действие |
|---|---|
| Q–I, A–K | Играть пэд, пока зажато |
| Delete | Удалить выбранную ноту |
| Space / Ctrl+Space | Play/pause и stop студии |
| Escape / × | Закрыть |
| Ctrl+S | Сохранить |
| Ctrl+колёсико | Зум сетки |
| Alt+колёсико | Горизонтальный скролл сетки |

ПКМ по ноте — удалить. Клик по сетке — поставить. Клик по пустому пэду не меняет высоту окна.

Инструмент сэмплинга — как в 0.1.1, плюс границы чопа только за треугольники.

## Структуры данных (runtime)

Источник правды: `src/model.rs`. Ниже поля, которых не было в 0.1.1 или которые уточнены.

```
Project
  notes: Vec<PadNote>
  seq_clips: Vec<SeqClip>
  next_note_id: u64
  next_seq_id: u64

SeqClip
  id: SeqId(u64)
  track_index: usize
  start_time_secs: f32             // на таймлайне
  duration_secs: f32

PadNote
  id: NoteId(u64)
  seq_id: SeqId                    // родительская колбаска
  slot: u8                         // 0..=15, тот же пэд
  start_time_secs: f32             // от начала SeqClip
  duration_secs: f32

PadMarker
  slot: u8
  start_index: usize               // включительно, в sample.data
  end_index: usize                 // исключительно

SamplerPreview                     // не пишется на диск
  playing: bool
  generation: u64
  track_index: usize
  start_secs: f32
  end_secs: Option<f32>            // стоп превью; None — до конца буфера
```

Микс студии в момент `t`: для каждой колбаски, если `t` внутри неё, `local = t - seq.start`; нота звучит, пока `local` внутри ноты; индекс PCM = `start_index + local_into_note * rate * track_speed`, пока `< end_index`.

Длительность колбаски по умолчанию: `beat_secs(tempo) * 4 * 4` (4 такта 4/4). Сетка нот: шестнадцатые, `beat_secs / 4`.

## Формат на диске

Как в 0.1.1, плюс:

```json
"pad_markers": [
  { "slot": 0, "start_index": 1200, "end_index": 4800 }
],
"seq_clips": [
  { "id": 1, "track_index": 0, "start_time_secs": 0.0, "duration_secs": 8.0 }
],
"notes": [
  { "id": 1, "seq_id": 1, "slot": 0, "start_time_secs": 0.0, "duration_secs": 0.25 }
],
"next_seq_id": 2,
"next_note_id": 2
```

Легаси: `{ "slot": 0, "sample_index": 1200 }` → регион от этой точки. Нет `seq_clips` — создаётся колбаска на трек. `format` = **1**.

## Ограничения (добавок к 0.1 / 0.1.1)

- Нет независимого time-stretch / pitch-shift; питч = скорость.
- Home (курсор к началу трека) не сделан.
- Исходный WAV на дорожке не редактируется как клип (trim/split/перекрытие); это буфер инструмента.
- Несколько колбасок на трек можно ставить внахлёст; микс их суммирует.
- Чопы и обзор инструмента по-прежнему не сериализуют курсор/зум.
