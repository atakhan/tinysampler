# tinysampler 0.1.1

Дата снимка: 2026-09-19. Соответствует пакету `tinysampler` **0.1.1**.

Опирается на [0.1.0](0.1.0.md). Здесь — дельта и актуальные структуры после пэдов в инструменте сэмплинга.

## Что изменилось относительно 0.1

### Инструмент сэмплинга

- Под основным waveform — сетка пэдов **2×8**.
  - 1-й ряд: `Q W E R T Y U I`
  - 2-й ряд: `A S D F G H J K`
  - Слот `0` — верхний левый (`Q`).
- **Курсор:**
  - *Базовая* позиция по умолчанию в начале сэмпла; клик по основному waveform ставит её (светлая линия + треугольник).
  - *Активная* — красная линия, едет во время превью.
  - Стоп (кнопка / Space) возвращает активный курсор к базовому. Плей стартует с базовой.
  - Клик во время превью меняет только базу, не сбивает текущее воспроизведение.
- **Метки на waveform (чопы)** привязаны к пэдам, не к студийным `1–9`:
  - Свободный пэд (клавиша или кнопка) ставит метку на **базовую** позицию.
  - Занятый пэд запускает превью с этой точки.
  - Метку можно перетащить; выбранную убрать `Delete` или `×` на фишке.
  - Больше 16 на трек не ставится. Загрузка нового сэмпла сбрасывает чопы.
- Навигация: Ctrl+колёсико — зум waveform; **Alt+колёсико** — горизонтальный скролл (waveform и карта).
- Пока окно открыто, студия некликабельна (таймлайн, транспорт, сайдбар). Затемнение не перехватывает клики самого окна (не всплывает поверх).
- Превью микширует **полный** буфер сэмпла (не timeline-trim).

### Сохранение

- `tracks[].pad_markers` пишутся в `project.json` (`slot`, `sample_index`).
- Старые проекты без поля читаются как пустой список (`serde default`). `format` по-прежнему **1**.
- При смене частоты устройства `sample_index` масштабируется как trim.
- Не пишутся: базовая/активная позиция курсора в инструменте, зум/скролл обзора.

## Горячие клавиши (инструмент)

Студия — как в 0.1. Пока открыт инструмент, студийные жесты и `M` / `1–9` не действуют.

| Клавиша | Действие |
|---|---|
| Space | Превью play / stop (stop → курсор к базе) |
| Escape / × | Закрыть инструмент |
| Ctrl+O | Загрузить WAV/MP3 |
| Ctrl+S | Сохранить проект |
| Q–I, A–K | Свободный пэд — метка на базу; занятый — play с метки |
| Delete | Удалить выбранную метку пэда |
| Ctrl+колёсико | Зум основного waveform |
| Alt+колёсико | Горизонтальный скролл обзора |

Клик по waveform — база. Клик по карте / drag карты — обзор. Клик по занятому пэду — как клавиша.

## Структуры данных (runtime)

Источник правды: `src/model.rs`. Ниже только поля, которых не было в 0.1 или которые уточнены.

```
Track
  name: String
  pitch_semitones: i32
  source_tempo_bpm: f32
  pad_markers: Vec<PadMarker>     // чопы инструмента, слот 0..=15

PadMarker
  slot: u8                        // 0..=15, уникален в пределах трека
  sample_index: usize             // индекс в sample.data (полный буфер)

SamplerPreview                    // не пишется на диск
  playing: bool
  generation: u64                 // рестарт превью с start_secs
  track_index: usize
  start_secs: f32                 // стенные секунды в сэмпл при generation bump
```

UI-only (не в `Project`): `sampler_base_secs` — базовая позиция курсора в инструменте.

Превью: `t_local` → индекс `t_local * device_sample_rate * track_speed` в `clip.sample.data`.

## Формат на диске

Как в 0.1, плюс у каждого трека:

```json
"pad_markers": [
  { "slot": 0, "sample_index": 1200 }
]
```

Отсутствующее поле = нет чопов. Дубли слотов при загрузке отбрасываются.

## Ограничения (добавок к 0.1)

- Пэд играет с метки до конца сэмпла (нет нарезки «до следующей метки»).
- Базовый курсор и обзор инструмента не сериализуются.
- Нет независимого time-stretch / pitch-shift; питч = скорость.
- Home (курсор к началу трека на таймлайне) не сделан.
