# tinysampler 0.1

Дата снимка: 2026-09-19. Соответствует пакету `tinysampler` **0.1.0**.

Это опорная версия: экраны библиотеки и студии, инструмент сэмплинга, таймлайн, метки, сохранение проектов на диск.

## Возможности

### Оболочка

- Нативное окно **egui / eframe**, тёмная тема, drag-and-drop файлов.
- При запуске окно сначала создаётся обычным размером, затем разворачивается (Windows: нельзя ставить `maximized` до `inner_size`, иначе кнопка «развернуть» врёт).
- `--test-tone` — 440 Hz ~1.5 с без GUI (проверка cpal).

### Библиотека проектов

- Стартовый экран: список проектов, «+ Новый проект».
- Открытие проекта ведёт в студию; «⌂ Домой» возвращает в библиотеку.
- Путь папки данных показан на экране проектов.

### Студия

- Верхняя панель: домой, play/pause, stop, табло времени (`mm:ss.mmm`), BPM проекта, имя проекта, статус.
- Линейка темпа 4/4 (такты и доли от `tempo_bpm`).
- Сайдбар: список треков, «сэмпл» (открыть инструмент), «+ Добавить трек».
- Дорожки: клипы с waveform, полоса меток над каждой дорожкой.
- Playhead, слежение при воспроизведении (ручной скролл временно отключает follow).
- Клипы: перетаскивание по времени и между дорожками, trim по краям выбранного клипа, Alt+drag — дубликат (ghost, без перекрытия после drop).
- На одной дорожке клипы не перекрываются; разные дорожки суммируются в миксе.
- Ctrl+колёсико — зум таймлайна; Alt+колёсико / drag пустого места — горизонтальный скролл.
- Клик по линейке или пустому месту дорожки — seek.

### Инструмент сэмплинга (модальное окно)

Открывается при добавлении трека и по кнопке «сэмпл».

- Play/stop превью (перехватывает вывод, таймлайн в это время молчит).
- Питч ±1 полутон, диапазон −24…+24 (`speed = 2^(n/12)`, классический sampler rate).
- Темп ±1 BPM (20–400); меняет `source_tempo_bpm` трека и `tempo_bpm` проекта (сетка линейки).
- Карта сэмпла ~60 px на всю длину + полупрозрачный прямоугольник текущего обзора.
- Основной waveform ~320 px; Ctrl+колёсико зумит; клик/drag по карте двигает обзор.
- Загрузка WAV/MP3 кнопкой или drop (только пока открыт инструмент).

### Метки

- `M` — метка 1–9 на **выделенном** треке у плейхеда; если слоты заняты, новая не ставится.
- Клавиши `1`–`9` — seek и play с метки выделенного трека.
- Фишку метки можно двигать; × удаляет; Delete удаляет выбранную метку (иначе выбранный клип).

### Аудио

- Вывод: **cpal**, без rodio. Проект в `ArcSwap` читается из callback.
- PCM всегда моно f32 в `[-1, 1]` на `device_sample_rate` (частота устройства на момент загрузки/создания проекта).
- WAV (int/float) и MP3 (symphonia); стерео → левый канал; ресемплинг на частоту устройства.
- Смена устройства (наушники → динамики): поток пересоздаётся; индекс сэмплов по-прежнему от `device_sample_rate`.
- Превью инструмента и транспорт студии не звучат одновременно.

### Сохранение

Корень (Windows): `%APPDATA%\tinysampler\`  
Переопределение: `TINY_SAMPLER_DATA_DIR`.  
Иначе: `~/.local/share/tinysampler` или `./tinysampler-data`.

Пишется при создании проекта, «Домой», Ctrl+S, автосохранение ~2 с после правок (не во время drag), закрытие окна.

Не сохраняются: play/pause, позиция плейхеда, превью инструмента, UI-zoom/скролл.

## Горячие клавиши

Студия (фокус не в текстовом поле):

| Клавиша | Действие |
|---|---|
| Space | Play / pause |
| Ctrl+Space | Stop (плейхед в 0) |
| Ctrl+S | Сохранить |
| Ctrl+O | Загрузить WAV/MP3 в выбранный трек / инструмент |
| Ctrl+K | Разрезать клип в плейхеде |
| Delete | Удалить метку или клип |
| M | Поставить метку 1–9 |
| 1–9 | Play с метки |

В инструменте сэмплинга: Space — превью, Escape / × — закрыть, Ctrl+O / Ctrl+S как выше.

## Структуры данных (runtime)

Источник правды: `src/model.rs`. Аудиопоток читает `Arc<Project>` через `ArcSwap`.

```
Project
  name: String
  device_sample_rate: u32          // частота PCM и таймлайна
  tempo_bpm: f32                   // линейка 4/4, 20–400
  next_clip_id: u64
  tracks: Vec<Track>
  clips: Vec<Clip>
  markers: Vec<CueMarker>
  transport: Transport             // не пишется на диск
  sampler_preview: SamplerPreview  // не пишется на диск

Track
  name: String
  pitch_semitones: i32             // playback speed 2^(n/12)
  source_tempo_bpm: f32

Clip
  id: ClipId(u64)
  track_index: usize               // индекс в Project.tracks
  start_time_secs: f32
  label: String                    // имя файла для UI
  sample: Sample
  trim_start, trim_end: usize      // полуинтервал в sample.data
  placement_preview: bool          // ghost при drag; не в миксе и не на диск

Sample
  data: Arc<Vec<f32>>              // моно, device_sample_rate
  peaks: Arc<PeakPyramid>          // только UI

CueMarker
  slot: u8                         // 1..=9, уникален в пределах трека
  time_secs: f32
  track_index: usize

Transport
  is_playing: bool
  stop_generation: u64             // стоп → сброс playhead в callback

SamplerPreview
  playing: bool
  generation: u64                  // рестарт превью с начала
  track_index: usize
```

Длительность клипа на таймлайне:  
`timeline_duration_secs / max(track_speed, 0.05)`  
(`timeline_duration_secs` = число видимых сэмплов / `device_sample_rate`).

Библиотека в памяти: `Vec<DiskProject>` (`id` + `Project` + карта указателей PCM → имя WAV).

## Формат на диске (`persist` format = 1)

```
<корень>/
  library.json
  projects/
    p{id}/
      project.json
      samples/
        s1.wav
        s2.wav
        ...
```

`library.json`:

```json
{ "format": 1, "next_project_id": 2 }
```

Список проектов при загрузке сканируется из `projects/p*/project.json` (не только из индекса).

`project.json` (поля):

| Поле | Смысл |
|---|---|
| `format` | `1` |
| `id` | id папки `p{id}` |
| `name` | имя проекта |
| `pcm_sample_rate` | частота сохранённых WAV |
| `tempo_bpm` | темп проекта |
| `next_clip_id` | следующий `ClipId` |
| `tracks[]` | `name`, `pitch_semitones`, `source_tempo_bpm` |
| `clips[]` | `id`, `start_time_secs`, `label`, `trim_start`, `trim_end`, `track_index`, `sample` (имя файла или null) |
| `markers[]` | `slot`, `time_secs`, `track_index` |

WAV: моно, 32-bit float, `pcm_sample_rate`. Один буфер `Arc` — один файл; неиспользуемые `sN.wav` удаляются. При загрузке, если частота устройства другая, PCM и trim масштабируются.

Запись JSON/WAV через временный файл и rename.

## Модули `src/`

| Файл | Роль |
|---|---|
| `main.rs` | Точка входа, окно, `--test-tone` |
| `app.rs` | Экраны, транспорт, жесты таймлайна, сохранение |
| `library.rs` | UI списка проектов |
| `sampler.rs` | UI инструмента сэмплинга |
| `model.rs` | Структуры проекта |
| `project_actions.rs` | Мутации: трек, сэмпл, trim, overlap, метки |
| `timeline.rs` | Геометрия дорожек, линейка, hit-test |
| `mix.rs` | Микс и превью (без аллокаций в callback) |
| `audio.rs` | cpal stream, playhead/preview atomics, recover устройства |
| `wav_loader.rs` | Decode WAV/MP3, ресемпл, запись float WAV |
| `waveform.rs` | Peak pyramid + отрисовка min/max |
| `persist.rs` | Папка данных, load/save |
| `theme.rs` | Константы UI |

## Ограничения 0.1 (не входят в снимок)

- Нет независимого time-stretch (длительность без питча) и независимого pitch-shift (высота без скорости). Питч = скорость воспроизведения.
- Клавиша Home (курсор к началу трека) не сделана.
- Нет удаления проекта из библиотеки, переименования в UI, undo/redo.
- Плейхед и транспорт не сериализуются.
- Один клип-сэмпл на трек в инструменте (загрузка заменяет буфер этого трека); на таймлайне клипов может быть больше после split/duplicate.
