# tinysampler

Десктопный мини-семплер на Rust: библиотека проектов, студия с дорожками и «колбасками», инструмент нарезки пэдов, воспроизведение через **cpal** (без rodio), интерфейс **egui** / **eframe**.

## Возможности

- **Библиотека** — список проектов, создание и открытие. PCM грузится только при открытии студии.
- **Загрузка WAV / MP3** — диалог или drag-and-drop в инструмент сэмплинга. Стерео сводится в левый канал. Частота файла **сохраняется в документе** (не привязана к текущему аудиоустройству).
- **Студия** — несколько дорожек, линейка темпа 4/4, sequence-клипы («колбаски»), пианоролл, метки 1–9.
- **Инструмент сэмплинга** — waveform, 16 пэдов (Q–I / A–K), питч = скорость `2^(n/12)`, темп проекта.
- **Микс** — звучат ноты внутри колбасок (сумма с ограничением амплитуды), не исходный WAV на дорожке.
- **Транспорт** — Play / Pause, Stop; слежение плейхеда; Space / Ctrl+Space.
- **Проверка аудио** — `cargo run -- --test-tone` (синус 440 Hz без окна).

## Как запустить

```bash
cargo run
cargo run -- --test-tone
cargo build --release
```

Данные: `%APPDATA%\tinysampler` (Windows), иначе `~/.local/share/tinysampler`. Переопределение: `TINY_SAMPLER_DATA_DIR`.

## Архитектура (кратко)

- UI пишет `Project`, аудиоколлбек читает `ArcSwap<Project>` (без Mutex/alloc в callback).
- Сэмпл принадлежит **треку** (`Track.sample`). Таймлайн — `SeqClip` + `PadNote`.
- Persist пишет в `p{id}.next`, затем подменяет каталог; битый WAV не валит весь проект.
