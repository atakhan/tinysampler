# tinysampler

Десктопный прототип мини-семплера на Rust: загрузка WAV, таймлайн с спектрограммой, воспроизведение через **cpal** (без rodio) и интерфейс **egui** / **eframe**.

## Возможности

- **Загрузка WAV** — диалог выбора файла; поддерживаются целочисленные и float-форматы; стерео сводится в **левый канал**; при несовпадении частоты дискретизации с устройством выполняется **ресемплинг** на частоту вывода.
- **Таймлайн** — линейка времени, дорожка с превью **спектрограммы** по каждому загруженному клипу, красный **плейхед**.
- **Навигация** — перетаскивание для горизонтального скролла; **Ctrl + колёсико** над таймлайном меняет масштаб (пикселей в секунду); клик по линейке или по пустому месту дорожки **перематывает** воспроизведение.
- **Транспорт** — Play / Pause, Stop (сброс плейхеда); при проигровании таймлайн слегка **подкручивается**, чтобы плейхед не уезжал к краю.
- **Смешивание** — если несколько клипов звучат в одну и ту же секунду времени проекта, сигналы **суммируются** (с ограничением по амплитуде).
- **Горячие клавиши** (когда фокус не в поле ввода текста): **Space** — play/pause, **Ctrl+Space** — stop, **Ctrl+O** (или **Cmd+O** на macOS) — открыть WAV.
- **Проверка аудио** — режим тестового тона 440 Hz для диагностики вывода (см. ниже).

## Системные требования

- **ОС:** Windows, macOS или Linux с рабочим **звуковым выходом по умолчанию** (то, что видит cpal как default output device).
- **Rust:** стабильный компилятор с поддержкой **edition 2021** (практически любой актуальный `stable`; при сомнениях обновите: `rustup update stable`).
- **Сборка:** стандартный набор для нативного GUI (зависит от платформы; на Windows обычно достаточно установленного **Visual Studio Build Tools** с компонентом «Разработка классических приложений на C++», если линкер об этом попросит).

## Как запустить

Из корня репозитория:

```bash
cargo run
```

Запуск **тестового тона** 440 Hz на ~1.5 с (без окна приложения):

```bash
cargo run -- --test-tone
```

Сборка релиза:

```bash
cargo build --release
```

Готовый бинарник: `target/release/tinysampler` (на Windows — `target\release\tinysampler.exe`).
