# tinysampler

Десктопный прототип мини-семплера на Rust: загрузка WAV и MP3, таймлайн с waveform, воспроизведение через **cpal** (без rodio) и интерфейс **egui** / **eframe**.

## Возможности

- **Загрузка WAV / MP3** — диалог выбора файла; WAV: целочисленные и float-форматы; MP3 через **symphonia**; стерео сводится в **левый канал**; при несовпадении частоты дискретизации с устройством выполняется **ресемплинг** на частоту вывода.
- **Таймлайн** — линейка времени, **несколько дорожек**, waveform по клипам, красный **плейхед**. Новый файл (кнопка «+», Ctrl+O или drag-and-drop) садится на **следующую** дорожку снизу.
- **Навигация** — перетаскивание клипа по дорожке; перетаскивание пустого места или **Alt + колёсико** — горизонтальный скролл; **Ctrl + колёсико** меняет масштаб; клик по линейке или по пустому месту дорожки **перематывает** воспроизведение. WAV/MP3 можно **перетащить в окно** из проводника.
- **Транспорт** — Play / Pause, Stop (сброс плейхеда); при проигрывании таймлайн слегка **подкручивается**, чтобы плейхед не уезжал к краю. Если во время Play скроллить вручную, слежение паузится, пока плейхед снова не попадёт во вьюпорт.
- **Смешивание** — если несколько клипов звучат в одну и ту же секунду времени проекта, сигналы **суммируются** (с ограничением по амплитуде).
- **Горячие клавиши** (когда фокус не в поле ввода текста): **Space** — play/pause, **Ctrl+Space** — stop, **Ctrl+O** (или **Cmd+O** на macOS) — открыть WAV или MP3.
- **Проверка аудио** — режим тестового тона 440 Hz для диагностики вывода (см. ниже).

## Системные требования

- **ОС:** Windows, macOS или Linux с рабочим **звуковым выходом по умолчанию** (то, что видит cpal как default output device).
- **Rust:** стабильный компилятор с поддержкой **edition 2021** (практически любой актуальный `stable`; при сомнениях обновите: `rustup update stable`).
- **Сборка:** стандартный набор для нативного GUI (зависит от платформы; на Windows обычно достаточно установленного **Visual Studio Build Tools** с компонентом «Разработка классических приложений на C++», если линкер об этом попросит).

## Как запустить

Из корня репозитория:

```bash
cargo run
```

Запуск **тестового тона** 440 Hz на ~1.5 с (без окна приложения):

```bash
cargo run -- --test-tone
```

Сборка релиза:

```bash
cargo build --release
```

Готовый бинарник: `target/release/tinysampler` (на Windows — `target\release\tinysampler.exe`).
