# ADR 001: Модель документа семплера

Дата: 2026-09-20.

## Контекст

Прототип начинался как клипы WAV на таймлайне (`Clip` + overlap/trim). С 0.1.2 студия играет **ноты в sequence-клипах**; исходный буфер — инструмент нарезки. Частота PCM была `device_sample_rate`. Persist удалял старые WAV до записи JSON.

## Решение

1. **Track владеет `Option<Sample>`.** Один буфер на дорожку. `Clip` как сущность таймлайна убран.
2. **Таймлайн = `SeqClip` + `PadNote`.** Связь дорожек через `TrackId`, не через индекс вектора.
3. **`Sample.sample_rate` — частота документа.** Микс индексирует PCM этой частотой; cpal stream только двигает время. Смена устройства не переписывает WAV.
4. **`Project.tempo_bpm` — единственный темп сетки и длины чопа по умолчанию.**
5. **Persist:** полный каталог в `p{id}.next`, затем publish (`p{id}` ↔ `.bak`). Отсутствующий сэмпл → предупреждение, проект открывается.
6. **Библиотека** хранит метаданные; PCM читается при Open. Открытый документ — один live `Project` в `ArcSwap`.

## Последствия

- Старые `project.json` с `clips[]` читаются: первый клип трека становится `Track.sample`.
- `format` остаётся 1 (аддитивные поля, `serde default`).
- Независимый time-stretch по-прежнему не входит в модель (питч = скорость).
