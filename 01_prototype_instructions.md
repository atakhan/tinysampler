# 🧠 Агентский протокол: прототип семпл-студии (Rust, desktop)

## 🎯 Глобальная цель

Собрать минимальное приложение:

* загрузка WAV
* размещение на таймлайне
* воспроизведение через аудио callback

---

# 📦 Общие правила (обязательно)

1. Все аудио:

   * mono
   * f32 [-1.0, 1.0]
   * sample_rate = как у устройства

2. В audio callback запрещено:

   * аллоцировать память
   * использовать Mutex
   * выполнять тяжёлые операции

3. Архитектура:

   * UI поток пишет состояние
   * Audio поток читает только snapshot

4. НЕ использовать rodio

---

# 🧪 Шаг 0: Проверка аудио пайплайна (синус)

## Цель

Подтвердить, что звук вообще работает

## Действия

* подключить cpal
* открыть default output device
* получить default config
* создать stream
* в callback генерировать синус 440Hz

## Формула

```rust
phase += 2.0 * PI * 440.0 / sample_rate
output[i] = sin(phase)
```

---

## ✅ Валидация

* слышен чистый тон 440Hz
* нет треска
* приложение не падает

❌ Если нет:

* остановиться
* исправить ДО перехода дальше

---

# ▶️ Шаг 2: Воспроизведение одного семпла

## Цель

Проиграть WAV без таймлайна

## Действия

* хранить один Sample
* в callback читать sample[i]

---

## Формула

```rust
output[i] = sample[current_index]
current_index += 1
```

---

## ✅ Валидация

* звук совпадает с оригиналом
* не ускорен и не замедлен

❌ Если искажения:

* проверить sample_rate

# 🧩 Шаг 3: Ввести Clip

## Цель

Добавить start_time

## Действия

* создать Clip
* задать start_time (например 1.0 сек)

---

## Формула

```rust
if t >= clip.start_time {
    local_time = t - clip.start_time
    index = local_time * sample_rate
}
```

---

## ✅ Валидация

* звук начинается не сразу, а через задержку

---

# ⏱ Шаг 4: Ввести Transport

## Структура

```rust
struct Transport {
    is_playing: bool,
    start_instant: Instant,
    pause_offset: f32,
}
```

---

## Логика

Play:

```text
start_instant = now
is_playing = true
```

Pause:

```text
pause_offset += now - start_instant
is_playing = false
```

Stop:

```text
pause_offset = 0
is_playing = false
```

---

## Валидация

* pause продолжает с того же места
* stop сбрасывает в 0

---

# 🧠 Шаг 5: Время внутри callback

## Ввести

```rust
audio_time: f32
```

## Обновление

```rust
audio_time += buffer_size / sample_rate
```

## Использование

```rust
t = audio_time + (sample_index / sample_rate)
```

---

## Валидация

* звук не “прыгает”
* нет рассинхрона
